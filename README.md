# Kubbe-Engine
Lenguaje específico de dominio (.brick) para videojuegos retro. Compilador en Python (tokenizador y parser) que genera JSON y motor en Tkinter que ejecuta Snake y Tetris. Proyecto en equipo de Teoría de Lenguajes de Programación

IMPORTANTE!! 
Leer los archivos README.txt e INSTALL.txt para poder entender como descargar y jugar los juegos.
